## Description

The goal of this project is to create a library and recreate some functions from libc and some other basic functions which will come in handy in other more complex projects.

There are three parts of this projects. The first one reproduces some functions
from libc, the second one reproduces some modified versions and/or new functions
and the third one is a collection of function to work with linked lists.

## Instructions

In order to generate de library use `make`.
